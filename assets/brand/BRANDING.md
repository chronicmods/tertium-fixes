# Tertium Fixes artwork

The existing artwork is retained for this release.

- `tertium-fixes-hero.jpg`: 1600 x 900 release artwork.
- `tertium-fixes-banner.jpg`: 1600 x 400 page banner.

The palette uses dark grey, bone, brass, amber and teal. Keep the title readable
when cropping or resizing. Tertium Fixes is an unofficial community mod.
